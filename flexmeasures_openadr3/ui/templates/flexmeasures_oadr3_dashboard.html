VEN clients represent the static connection settings that a Virtual End Node (VEN) needs to communicate with a Virtual Top Node (VTN) — the VTN URL, OAuth credentials, and scopes. Each VEN client can have one or more polling schedules that define what DR events to fetch, when to fetch them, and which FlexMeasures sensors to store the retrieved capacity-limit beliefs in.
