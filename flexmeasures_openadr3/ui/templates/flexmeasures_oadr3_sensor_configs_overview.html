A polling schedule defines when and what to fetch from the VTN using the HTTP polling interface. Each schedule runs daily at the configured trigger time, retrieves DR events matching the specified targets, and stores the resulting capacity-limit beliefs in FlexMeasures sensors. You can create multiple schedules per VEN client — for example, to poll different targets or limit types independently.
