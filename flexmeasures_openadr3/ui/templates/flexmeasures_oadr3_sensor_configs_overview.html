A polling schedule defines when and what to fetch from the VTN using the HTTP polling interface. Each schedule is a FlexMeasures automation on the VEN client's asset: whenever its cron schedule is due, it retrieves DR events matching the specified targets and stores the resulting capacity-limit beliefs in FlexMeasures sensors. You can create multiple schedules per VEN client — for example, to poll different targets or limit types independently. Use the asset's Automations page to run a schedule now, (de)activate it, or inspect its recent runs.
